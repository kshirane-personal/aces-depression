# 解析ワークフロー

本ドキュメントは、ACEs-予防医療行動-うつ病交互作用研究の解析作業を段階的に記述したものである。研究者が現在地を把握し、次に何を行うべきかを判断するための実務的な手順書として機能する。

研究の背景・目的・意義については `docs/research_plan.md` を参照のこと。

## 凡例

- **確定**: 現時点で決定済みの事項。変更の可能性は低い。
- **仮説ベース**: データの状態や中間結果に応じて修正・撤回の可能性がある事項。判断材料が揃った時点で確定に昇格させる。
- **状態**: 各フェーズの進捗を `未着手` / `進行中` / `完了` で示す。

### 1-4. 予防医療行動変数の選定 — 複合指標は構成しない（確定）


| 判断ポイント       | 内容                                              | 区分    |
| ------------ | ----------------------------------------------- | ----- |
| 複合スコアの作成     | **作らない。** 個別変数のまま扱う                            | 確定    |
| 主解析に使う変数     | **CHECKUP1 と FLUSHOT7 の2変数を事前指定**              | 確定    |
| 探索的記述に回す変数   | LASTDEN4、HIVTST7                                | 確定    |
| 解析から除外する変数   | がん検診系5変数（HADMAM, CRVCLPAP, CRVCLHPV, STOOLDN2, PSATEST1） | 確定    |


**複合指標を作らない根拠**: 利用可能な4変数の相互相関は 0.16〜0.21 と低く、HIVTST7 は
他の3変数とほぼ無相関（-0.06〜-0.01）。単一次元性を前提とした合成は支持されない。
「ヘルスケア・エンゲージメント」は考察における解釈の枠組みとしてのみ用い、
分析設計・仮説の文言からは外す（`docs/research_plan.md` 3.1 参照）。

**がん検診系を除外する根拠**: 欠損が構造的（性別・年齢による質問対象の限定、
オプショナルモジュールの州別実施状況）であり、多重補完の適用が不適切。
PSATEST1 は13州・地域のうち10地域でモジュール未実施。

**主解析2変数の選定理由**: CHECKUP1 は予防医療への定期的な関与を最も直接的に表す。
FLUSHOT7 は実施率45.5%で群間のバランスが良く、交互作用の検出力の面で有利。
