## 2. ACEs変数（逆境的小児期体験）

### 2a. 家庭内の機能不全（はい/いいえ形式）

| 変数名 | 質問内容 | 値 | ACEカテゴリ |
|--------|----------|-----|------------|
| ACEDEPRS | うつ病・精神疾患・自殺傾向のある人と同居していたか | 1=はい, 2=いいえ, 7=わからない, 9=回答拒否 | 家庭内の精神疾患 |
| ACEDRINK | 問題飲酒者・アルコール依存症の人と同居していたか | 1=はい, 2=いいえ, 7=わからない, 9=回答拒否 | 家庭内の物質依存 |
| ACEDRUGS | 違法薬物使用・処方薬乱用の人と同居していたか | 1=はい, 2=いいえ, 7=わからない, 9=回答拒否 | 家庭内の物質依存 |
| ACEPRISN | 刑務所に服役した人と同居していたか | 1=はい, 2=いいえ, 7=わからない, 9=回答拒否 | 家族の収監 |
| ACEDIVRC | 親が離婚・別居したか | 1=はい, 2=いいえ, 7=わからない, 9=回答拒否 | 親の離婚・別居 |

### 2b. 虐待（頻度形式）

| 変数名 | 質問内容 | 値 | ACEカテゴリ |
|--------|----------|-----|------------|
| ACEPUNCH | 親や同居の大人に殴る・蹴る等の暴力を受けた頻度 | 1=1回, 2=2回以上, 3=なし, 7=わからない, 9=回答拒否 | 身体的虐待 |
| ACEHURT1 | 親や同居の大人に痣・怪我を負わされた頻度 | 1=1回, 2=2回以上, 3=なし, 7=わからない, 9=回答拒否 | 身体的虐待 |
| ACESWEAR | 親や同居の大人に罵倒・侮辱された頻度 | 1=1回, 2=2回以上, 3=なし, 7=わからない, 9=回答拒否 | 精神的虐待 |
| ACETOUCH | 5歳以上年上の人または大人に性的接触を受けた頻度 | 1=1回, 2=2回以上, 3=なし, 7=わからない, 9=回答拒否 | 性的虐待 |
| ACETTHEM | 5歳以上年上の人または大人に性的接触を試みられた頻度 | 1=1回, 2=2回以上, 3=なし, 7=わからない, 9=回答拒否 | 性的虐待 |
| ACEHVSEX | 5歳以上年上の人または大人に性行為を強制された頻度 | 1=1回, 2=2回以上, 3=なし, 7=わからない, 9=回答拒否 | 性的虐待 |

### 2c. ネグレクト（逆転項目）

| 変数名 | 質問内容 | 値 | ACEカテゴリ |
|--------|----------|-----|------------|
| ACEADSAF | 子供時代、安全・守られていると感じた頻度 | 1=いつも, 2=ほとんど, 3=ときどき, 4=たまに, 5=全くない, 7=わからない, 9=回答拒否 | 情緒的安全（逆転） |
| ACEADNED | 子供時代、基本的な必要を満たそうとしてくれた頻度 | 1=いつも, 2=ほとんど, 3=ときどき, 4=たまに, 5=全くない, 7=わからない, 9=回答拒否 | 基本的ニーズ（逆転） |

### ACEスコアの算出方法

11の質問項目を以下の8カテゴリに集約し、各カテゴリの該当有無（0/1）を合計してACEスコア（0-8）を算出する。

| カテゴリ | 使用変数 | 二値化ルール |
|----------|----------|-------------|
| 精神的虐待 | ACESWEAR | 1回以上あり → 1 |
| 身体的虐待 | ACEPUNCH, ACEHURT1 | いずれか1回以上あり → 1 |
| 性的虐待 | ACETOUCH, ACETTHEM, ACEHVSEX | いずれか1回以上あり → 1 |
| 家庭内の精神疾患 | ACEDEPRS | はい → 1 |
| 家庭内の物質依存 | ACEDRINK, ACEDRUGS | いずれかはい → 1 |
| 親の離婚・別居 | ACEDIVRC | はい → 1 |
| 家族の収監 | ACEPRISN | はい → 1 |
| DV目撃 | ACEPUNCH | 1回以上あり → 1 |
