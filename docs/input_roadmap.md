## 段階1: 研究内容のインプット

### ① ヘルスケア・エンゲージメントの機序 — 最優先

**本研究で最も弱く、最も質問される部分。**

`research_plan.md` 1.1 は Andersen の医療サービス利用行動モデルを引いて、予防医療行動を「ヘルスケア・エンゲージメント」という上位概念で捉えている。しかし押さえるべきは次の問いである。

> インフルエンザ予防接種を受けることが、なぜACE由来のうつ病を緩衝しうるのか

考えられる筋は複数あり、どれを主張するかで研究の意味が変わる。

| 機序 | 含意 | 問題点 |
|---|---|---|
| 医療アクセスの確保そのものが保護的 | 資源としての医療 | 保険加入等を調整すると効果が消えるかもしれない |
| 受診行動が自己効力感・社会的つながりの代理指標 | 予防医療は「印」であって原因ではない | 介入可能性の主張が弱くなる |
| 受診機会がうつ病の早期発見・治療につながる | 臨床的示唆が明確 | **検出バイアスと同じ経路**。注意 |

**自分の立場を決めておく必要がある。**

参考になるデータ（今回の前処理で判明）: コア4変数の相関は 0.16〜0.21 と低く、`HIVTST7` は他の3つとほぼ無相関（-0.06〜-0.01）。「単一の構成概念」という前提への反証になりうる。

### ② ACEs研究の基礎

- Felitti 1998 のオリジナル研究。なぜ8〜10カテゴリという構成になったか
- **用量反応関係** — ACEスコアが増えるほどリスクが上がる。「4以上」が閾値として定着した経緯
- 生物学的機序 — toxic stress、HPA軸、慢性炎症。「なぜ子ども時代の経験が数十年後のうつ病に効くのか」
- 回顧的自己申告の妥当性 — 過少申告の傾向（`research_plan.md` 7.1 にも記載）

### ③ うつ病の疫学と測定

- 有病率の相場観 — 本データは20.2%（生涯診断歴）。これが高いのか妥当なのかの判断軸
- **生涯診断 vs 現在症状**の違い
- BRFSS の `ADDEPEV3` が何を測っているか、先行研究でどう扱われてきたか
- `MENTHLTH` / `_MENT14D`（14日以上のメンタル不良）が代替指標としてどう使われてきたか

### ④ 先行研究の空白の確認

`research_plan.md` 1.1 は「体系的な検証はほとんど行われていない」と主張している。**学会発表で最初に突っ込まれるのはここ。** 計画書自身が「身体活動がACEsの影響を緩和する研究は存在する」と書いているので、予防医療行動についても類似研究がないか自分で確認しておく。

## 段階2: 方法論のインプット

### ⑤ 加法的交互作用と乗法的交互作用 — 最優先

主仮説H1の"緩衝"がどちらの尺度の話なのかで結論が変わる。ロジスティック回帰の交互作用項は乗法尺度、RERIは加法尺度で、**片方で有意でもう片方で非有意は普通に起きる**。

フェーズ4-1（交互作用項）と4-2（RERI）は別の問いに答えている。公衆衛生的な含意は加法尺度側にあるので、発表のストーリーにも直結する。

押さえること: RERI・AP・SIの定義と解釈、なぜ加法尺度が公衆衛生上重要とされるか、信頼区間の求め方（デルタ法の不安定さ）。

### ⑥ 構造的欠損（missing by design） — Issue #1 が解ける

「30%以上は変数除外、5-30%はMICE」を機械適用すると曝露変数9つのうち5つが消える。しかしその欠損は設計上聞かれていないもの。

```
PSATEST1  93.5%欠損  13地域中10地域でモジュール未実施 + 男性限定 + 年齢限定
HADMAM    45.6%欠損  男性100% / 女性0.3%（純粋な性別ゲート）
STOOLDN2  79.7%欠損  全州で約80%。年齢ゲート + 他の検査を選んだ人のスキップ
```

MICEは「観測された情報から推測できる」前提に立つので、そもそも質問されていない人の回答を埋めるのは不適切。

押さえること: MCAR/MAR/MNARの定義、missing by design がどれにも当てはまらないこと、該当集団内分析（restricted analysis）への切り分け、Little's MCAR検定の限界。

### ⑦ DAG・over-adjustment・効果修飾 — Issue #2 が解ける

健康行動（喫煙・飲酒・運動）を中間変数とするか交絡因子とするかで調整変数セットが変わる。

押さえること: バックドア基準、中間変数を調整する害（over-adjustment）、コライダー層別化バイアス、そして**DAGは効果修飾を表現できない**という限界。

最後の点は重要。本研究の主題は効果修飾（ACEs × 予防医療行動）だが、DAGは因果構造を書くもので交互作用の有無はDAG上に現れない。DAGで決まるのは調整変数であって交互作用の妥当性ではない。

DAGitty のチュートリアルを一周すれば手を動かしながら概念も入る。

### ⑧ 複合サーベイデザインの解析

BRFSSは層化多段抽出なので単純な集計・検定はすべて誤りになる。

押さえること: 抽出ウェイトの意味、デザイン効果、Taylor級数展開とレプリケイト法による分散推定、Rao-Scott補正がなぜ必要か。

`svy` の使い方は着手時でよいが、**なぜウェイトなしだと標準誤差が過小になるか**は先に理解しておく。

### ⑨ 横断研究の限界・逆因果・検出バイアス

発表でほぼ確実に聞かれる。本研究には二重の弱点がある。

- 横断データなので時間的前後関係が立てられない
- `ADDEPEV3` は**生涯診断歴**であり現在のうつ状態ではない

さらに検出バイアス（予防医療行動が多い→医師との接触が多い→診断されやすい）がある。ただしこれはH1と**逆向き**に働くため、H1が支持された場合の推定値は保守的と主張できる。発表で使える論点。

```markdown
## 出力形式

2. 調査項目ごとの回答（主張 → 根拠 → 出典）

4. 未解決の論点
5. 出典一覧（著者 / タイトル / 掲載誌 / 発行年 / DOI・URL / アクセス日）
```

## プロンプト4: 構造的欠損（missing by design）の扱い

```markdown
# 調査依頼

## 目的
調査設計上そもそも質問されていない変数（スキップパターン、オプショナルモジュール未実施、
性別・年齢によるゲート）の欠損を、統計解析でどう扱うべきかを判断する。

- 除外: 縦断研究の脱落（attrition）のみを扱った研究

5. オプショナルモジュールが一部の地域でのみ実施されている場合、その変数を使った分析は
```
